Creator Studio now uses English across the web app, Windows app, provider errors, research reports and bundled documentation.

- English navigation, forms, accessible labels, empty states, exports, Windows menus and connection settings.
- New AI scripts are requested in English, including when the brief uses another language.
- Existing topics, profiles, scripts and original TikTok content keep their language. Known legacy tone selections migrate to English without changing your brief.
- English setup, publishing and API guides, with release-language checks in CI.

**Windows upgrade:** close the old app, back up your data, extract the entire new ZIP into a separate folder and open `Creator Studio.exe`. Data and encrypted settings remain in `%APPDATA%\Creator Studio`. No login or separate Java installation is required. Supply your own Gemini and RapidAPI keys in Settings.

The Windows x64 build is unsigned and does not auto-update. Desktop/web data do not synchronize automatically. Research reports describe public-content signals, not verified private demographics or guaranteed virality.
