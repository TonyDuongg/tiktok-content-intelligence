Save TikTok channel and target-audience profiles to compare channels using public data.

- Reusable profiles for your channel, audience, offering, goals, keywords and TikTok Studio notes.
- Reopen saved channels without another RapidAPI request.
- Audience & trends reports with content-match ratios, excluded topics, evidence, repeated hashtags and duration groups.
- View-count observations on channel refresh. Measured growth requires two observations of the same video at least one hour apart.
- Send supported experiments into the script studio with audience context, duration and a reference; export JSON reports.
- Window-sized desktop layout with collapsible search and separate scrollable content panes.

Content overlap is not verified customer overlap. Private audience demographics and guaranteed trend forecasts are unavailable. See `docs/RESEARCH.md` for methodology and limits. This historical binary retains its Vietnamese interface; use v1.1.1 or later for English.

To upgrade, close the old app, back up data, extract the entire ZIP into a separate folder and open `Creator Studio.exe`. Data/settings remain in `%APPDATA%\Creator Studio`. No login or separate Java installation is needed. Users supply their own API keys. Windows builds are unsigned and do not auto-update.
